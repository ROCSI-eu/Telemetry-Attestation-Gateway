## Exact local format

The technical hypothesis is one synthetic scalar witness within a public uint32 bound in cm/s, including equality. This spike tests software format and decision semantics, not witness knowledge or observation binding. The fixture corpus contains no real telemetry, witness, secret, stable source identifier or actual proof. The reference codec reuses the v0 integer CBOR head/argument helpers only; text-key structures are implemented here. The separate checker parses canonical bytes using a cursor and independently reconstructs input bytes from canonical field slices, sharing no codec or business-logic implementation. Both implementations are AI-assisted in one mandate: no independent human author/reviewer claim.

Wire: deterministic CBOR, unsigned shortest form through uint64, bytes, NFC UTF-8 text, arrays and text-key maps only. Key order is lexicographic on encoded key bytes; reject duplicates, nonminimal, unknown fields, wrong types, trailing data and noncanonical bytes. Local bounds: 8192 wire bytes, depth 8, 32 items per container, nonempty printable ASCII IDs 1–255 characters, uint32 versions and maximum, uint8 assurance, 32-byte digests/commitment/nullifier, attached payload 1–1024 bytes. No float, negative integer, bool, tag, indefinite or null on wire. Structural checks precede supported-profile checks. Unknown wire versions with this known shape return unsupported; arbitrary future schemas are outside this parser.

Required map keys in public-input order (not map serialization order):

| Order | Name | Local profile |
| --- | --- | --- |
| 1 | envelope_version | [1,0] |
| 2 | statement_id | tag.experimental.scalar-speed.v1 |
| 3 | proof_suite | tag.experimental.placeholder.v1 |
| 4 | assurance_tier | 0 = A0_SYNTHETIC |
| 5 | policy_ref | exact map id/version/digest, test-policy / 1 / SHA256 of ASCII TAG-TEST-POLICY-V1 |
| 6 | validity | exact uint64 not_before/not_after, lower inclusive, upper exclusive, nonempty |
| 7 | domain | tag.synthetic.local |
| 8 | commitment | opaque 32-byte fabricated field, not computed commitment |
| 9 | nullifier | opaque 32-byte fabricated field, not computed nullifier |
| 10 | verification_key_id | exact map id/version/digest, test-key / 1 / SHA256 of ASCII TAG-TEST-KEY-V1 |
| 11 | public_inputs | exact map maximum_speed_cm_s uint32 |

The twelfth required key proof is an exact map kind=attached, content_type=application/vnd.tag.placeholder, bytes. For local deterministic mutation tests the payload is ASCII PLACEHOLDER: followed by SHA256 of ASCII TAG-SYNTHETIC-INPUTS-V1, one NUL byte, then canonical CBOR of the eleven-element ordered array above. The statement/suite IDs are the sole test-only schema/circuit aliases, not registered cryptographic identifiers. There is no field-element conversion, actual circuit, proof, key, commitment opening or private witness. Anyone can recompute the placeholder: it has **zero cryptographic proof or authentication value**. The digest is only a deterministic fixture-consistency mechanism. Referenced proof and ledger receipt structures are shape-checked then unsupported; no retrieval or publication path. Other tiers, versions, statement/suite and media types are unsupported. No migration from v0 or compatibility assertion.

## Result contract and simulation

Outer report always has experimental labels, mode NON_CRYPTOGRAPHIC_PLACEHOLDER, actual_crypto NOT_CHECKED, verification NOT_PERFORMED, and admission malformed/unsupported/structurally_accepted. Structurally accepted reports include reconstructed public-input hex and a separately nested simulated_result. Malformed/unsupported reports have no simulated outcome, because the tier and other dimensions may not be established. This is a diagnostic spike schema, not the canonical verifier-result API. Never flatten simulated_result into actual cryptographic result.

The fixed, explicitly artificial scenario describes decision_time (uint64 or unavailable), artifact availability, policy permission, revocation state, already-seen and store-available booleans, assurance sufficiency and optional publication-unavailable flag. All context is supplied by the test harness; no authenticated policy, trusted clock, real revocation, actual store transaction or proof verification occurs. Freshness tests use [100,110), no skew; policy/key fixed digest comparisons and placeholder consistency yield simulated invalid before unavailable. Contextual negatives do not rewrite simulated envelope validity. Optional publication unavailable is diagnostic only; required publication and receipts are outside this selected profile. Replay accepted is a simulated possibility when all prerequisite dimensions are positive, never a durable insertion. Assurance insufficient assumes known effective A0 but a higher hypothetical requirement; unavailable is separate. Reason codes are local dimension/value pairs. No business decision is emitted. Above-limit scalar witness behavior is covered by prior v0 fixtures, not this placeholder.

## Local synthetic binding composition

[Binding adapter](binding_adapter.py) is a separate synthetic test-only admission path over the unchanged codec and corpus. It imports the existing authorized frame digest, TemporalGate, ingress receipt authentication and PersistentUnified directory lock/atomic writer. It never instantiates Unified, calls its proof callback, accesses an authentic proof or invokes Barretenberg. The source must have exactly one signed GLOBAL_POSITION_INT primary; up to eight observation events are accepted, with verifier-owned synthetic enrollment. The normalized integer speed is independently checked against the fixed public test threshold 500 cm/s. Equality passes; above-bound is rejected before state commit, not called cryptographic INVALID.

The local profile uses distinct 32-byte synthetic source, ingress, status and source-opening keys. An independently supplied exact status SHA256 pin and HMAC authenticate a fixed scope, test policy/key digests, threshold, half-open issue/expiry time and revocation flag. Status and ingress use the frozen configured synthetic decision clock. Ingress must be on an exact second and envelope validity must equal [ingress_seconds, ingress_seconds+10); no skew. This is reception time, not sensor time. Status is a pinned test snapshot, not an authoritative registry, signature PKI or revocation distribution system; selecting the newest pin and preventing rollback of the trusted configuration remain external requirements.

Candidate opening construction (not a registered suite or circuit): HMAC-SHA256 with distinct ASCII domain tags followed by NUL and deterministic CBOR. Source commitment = HMAC(source_secret, tag TAG-SYNTHETIC-SOURCE, array alias); record commitment = HMAC(private 32-byte nonce, tag TAG-SYNTHETIC-COMMITMENT-V1, array version, statement, suite, tier, policy_ref, validity, domain, verification_key_id, public_inputs, authorized BLAKE2s frame digest, normalized speed, source commitment); nullifier = HMAC(nonce, tag TAG-SYNTHETIC-NULLIFIER-V1, array source commitment, domain, policy digest, statement). The verifier in this private synthetic test harness sees the capture, speed and nonce to check openings; this is **not** a zero-knowledge verifier boundary. Public test keys and deterministic test openings have no secret/assurance value. No claim of hiding, unlinkability, approved construction, circuit binding or actual proof knowledge. Changing the frame even with a newly authenticated ingress receipt must fail opening comparison. No source pseudonym or frame digest is exported in the result. The public placeholder token remains freely reproducible.

The same locked record atomically commits staged source watermark plus sorted scoped nullifier set (maximum 64, no eviction), only after all checks pass. Owner-private 0700 directory and 0600 regular single-link state, exact canonical bytes and checksum, scope and authority fingerprints; explicit initialization only; missing/corrupt or changed key configuration fails closed. Concurrent cooperating submissions yield at most one synthetic admission (loser may be busy or replayed). Atomic replace/fsync reused; uncertain post-replace fsync returns HOLD, state may already have advanced, no automatic retry. Trusted filesystem/owner, no hostile-owner or restored-state rollback protection, no distributed replay protection, no production key rotation. Do not retain runtime state outside temporary tests.
